# Kumar Babu Kesam — Portfolio

A responsive, single-page portfolio built from the content in Kumar Babu Kesam's resume and inspired by the structure of the referenced portfolio at https://kalyan-aravalli.github.io/Portfolio/.

## Files

- `index.html` — portfolio page
- `style.css` — responsive styling and layout
- `script.js` — mobile navigation and dynamic footer year
- `Kumar-Babu-Kesam-Resume.pdf` — resume download used by the page

## Run locally

Open `index.html` in a browser. No build step is required.

## Deploy to GitHub Pages

1. Create a GitHub repository, for example `portfolio`.
2. Upload all files from this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select the default branch and `/ (root)`.
5. Save and wait for GitHub Pages to publish the site.

The site uses Google Fonts from CSS; the rest of the portfolio is self-contained.
